## GM formula comparison

The default stable solver uses the same first-order accumulation and background
coefficient 0.5 as the original notebook. It solves the two-parameter fit by
least squares and evaluates the analytical response difference with expm1 and
a near-zero series. Constant coordinates retain their constant value.
The archived original functions are preserved in `legacy/original_1124_core.py`.

An end-to-end attempt with the legacy formula on the artificial ellipse set
encountered a nonfinite coordinate. The release raises an error rather than
silently replacing that output. Use of the stable default is disclosed; this
does not establish historical prediction accuracy or remove all contour-shape
artifacts. The optional residual-corrected notebook cell is not part of the
standard solver.

## Reproduction scope

The vehicle and component checks use the located current input files, whose
names and SHA-256 hashes are in `located_input_manifest.json`. Numerical parity
with an existing computational cache is not the same as verification against
every published manuscript table. The exact original inputs are needed for
that further check.

The full original fifteen-image SA history was not located during this
packaging task. The GM end-to-end check therefore uses explicitly artificial
inputs generated by `make_demo_inputs.py`, not research results. This release
does not claim exact reconstruction of the manuscript's SA prediction figures,
held-out prediction validation, or performance superiority over baselines.

## Files intentionally outside the release

Original website photographs, real contour PNGs, local virtual environments,
VGG checkpoints, questionnaire responses, manuscript Word files and prior
generated outputs are outside this code package. The three provided notebooks
have cleared outputs and no embedded figures.
